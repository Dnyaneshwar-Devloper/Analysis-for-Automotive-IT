<summary><b>🛰️ Chapter 1: Vehicle Telematics & IoT</b></summary>
<br>

> Master this data pipeline to build modern connected vehicle apps, telematics engines, and predictive analytics modules.


| Term | Definition | Analytical Use Case |
| :--- | :--- | :--- |
| **CAN Bus** | Controller Area Network protocol enabling onboard microcontrollers to exchange information directly. | Primary bus network for decoding raw vehicle health packets. |
| **OBD-II Interface** | Standardized diagnostic interface physical port inside consumer vehicles. | Hardware scanning gateway used to extract emission and real-time powertrain stats. |
| **DTC** | Diagnostic Trouble Codes consisting of five-digit standardized diagnostic fault strings. | Triggering prompt diagnostic tickets and pinpointing engine sub-component failures. |
| **Payload** | Raw telemetry packets containing speed, GPS coordinates, and various engine health matrix vectors. | Streaming processing engines updating cloud infrastructure over MQTT or HTTP. |
| **Mileage Profiling** | Predictive analytical monitoring of accumulated vehicle odometer metrics. | Generating personalized user degradation warnings and automated component service cycles. |

</details>

<summary><b>🏭 Chapter 2: Manufacturing & Supply Chain</b></summary>
<br>

> Core operational parameters designed to maximize line efficiency, control carryover overheads, and guarantee full part lineage tracking.

*   **OEE (Overall Equipment Effectiveness):** Fundamental baseline metric evaluating line productivity, availability, and assembly quality standards.
*   **Predictive Maintenance (PdM):** Utilizes historical factory machine vibration arrays and ML classification tools to mitigate unplanned down-times.
*   **Lead Time Variance:** Tracks timing deviations separating supplier order points from factory receiving dock timestamps.
*   **SKU Rationalization:** Applies deep inventory ledger analytics to prune redundant part variations and shrink structural holding liabilities.
*   **Traceability Matrix:** Links assembly lineages completely from original foundry batches to final VIN validation checks.

</details>
